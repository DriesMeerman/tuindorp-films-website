# Tuindorp Films

Een Nederlandstalig, onafhankelijk onderzoeksdossier. Het onderzoek heeft nog geen organisatie onder de exacte naam Tuindorp Films kunnen verifiëren. De site benoemt die beperking en scheidt gevonden films over tuindorpen van producties van de gezochte organisatie.

De bronverwijzingen en zoekverantwoording staan op de website zelf. De site presenteert zich niet als officiële bedrijfswebsite. Zoekmachine-indexering staat uit zolang de identiteit niet is bevestigd.

## Lokaal bekijken

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000. Er is geen bouwstap. HTML, CSS en het favicon staan in de hoofdmap. De Google Fonts zijn optioneel. Bij ontbrekende netwerktoegang gebruikt de site Arial.

## Publicatie

GitHub Pages kan de hoofdmap van de branch `main` publiceren. `.nojekyll` schakelt Jekyll uit. Tijdelijke bestanden en screenshots in `.fang-artifacts/` staan buiten Git.

## Inhoud aanvullen

Controleer eerst een bron die de exacte organisatienaam aan makers en producties verbindt. Werk daarna de tekst, onderzoeksdatum, bronverwijzingen en eventuele robots-instelling in `index.html` bij.
